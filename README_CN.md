# Salience Ledger

Salience Ledger 是面向长期 AI 任务的确定性、来源优先记忆控制层。它由内部系统 EvoS 演进而来，
解决的不是“能否搜到旧对话”，
而是上下文压缩后，代理会不会忘掉最关键的用户规则、永久否决、反例和未解决阻塞。

核心原则：原始事件只追加；摘要不具有权威；重点记忆固定进入恢复上下文；冲突未解决则拒绝构建；
永久否决不能被工程提案偷偷复活；仍有阻塞或反例回归未通过时不能宣称完成。

当用户前后两次语义存在歧义时，系统必须同时展示两次原话和来源并请求确认；禁止默认采用最新说法，
因为用户也可能忘记先前决定。只有新的 `user_confirmation` 事件才能完成显式消歧。

详细用法见 [README.md](README.md) 和 [架构说明](docs/architecture.md)。
